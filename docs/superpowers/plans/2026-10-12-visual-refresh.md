## Review Focus

These are the conditions the spec implies but doesn't spell out, most likely to bite a rider first. Each has a test in the task named.

1. **A feed that has already ended, or ends today** (`last` on or before `first`): the picker shows only "Today", hides quick picks that land after `last`, and never throws. → Task 9, "a feed that ends today".
2. **Times across midnight and noon:** "In 15 min" at 23:50 lands on Tomorrow, and in 12-hour mode 12 AM is hour 0 and 12 PM is hour 12. → Task 9, "quick picks" and "12-hour mode".
3. **Two departures of the same trip at one stop** (a loop route passing twice, or a feed that repeats a row): keyed rows must not collide. → Task 8, "the same trip twice at one stop" (and the existing overflow fixture, whose rows share a trip and a time).
4. **2× text under the frosted top bar:** the first item starts below the bar, not hidden under it. → Task 10, "content starts below the bar at 2× text".
5. **Never-ending loops** (live dot, skeleton shimmer): they must leave frame-free rests and stop under Reduce Motion. Otherwise a screen with live data never settles: tests hang and the battery drains. → Task 6, "BBLiveDot rests between breaths", and Task 7, "the shimmer rests between sweeps".

## Spec ambiguities resolved here

- **Picker signature:** spec §4.1 lists `initial`, `first`, `last` and `use24h`, but the sheet needs its "Leave by"/"Arrive by" title. This plan adds a required `title`. `first` is "now": days start at its day, a time before it is "in the past", and "Use now instead" returns `first`.
- **Day chips beyond a week:** "Today", "Tomorrow", then "Thu" up to six days out, then "Thu 15" so later weeks stay distinct. Chips run all the way to `last` in a horizontal scroll.
- **Fixed quick picks** use `BBTime` like every other time in the app ("08:00"/"17:00", or "8:00 AM"/"5:00 PM"). They land on the next 8:00 or 17:00 after `first`. Quick picks that land after `last` are hidden.
- **Focus ring:** bright green on white is 2.85:1, under 3:1. So the 2 px focus ring and the selected-segment edge use `BBTokens.brandEdge`, which is `brandInk` in light and `brand` in dark (spec §2.2).
- **"warn" in the route ΔE rule** is `warnInk` of each mode.
- **Route hues:** `green` becomes `ocean` (teal-blue `#2D7BB2`) and `lime` becomes `olive` (`#7C8A1C`). They keep their enum positions, so `RoutePalette.of` fallbacks don't move. `indigo`, `lilac` and `sky` lines move too, because they sat within 0.08 of the new `accent`. The `assigned` table doesn't change, so routes that share stops still differ.
- **Location ping:** maplibre_gl 0.27 exposes no styling for its native location puck. The ping is our own `BBPing` ring, played at the map centre after "My location" centres the map: two 1.6 s rings, then nothing, and none under Reduce Motion. A truly endless loop would need native plugin work.
- **Live dot breathing:** each 1.6 s `pulse` cycle is an 800 ms breath and an 800 ms rest. The rest leaves frame-free gaps (see Review Focus 5). The same run-then-rest pattern drives the skeleton shimmer (1 s sweep, 0.6 s rest).
- **Chips "slide":** segmented controls slide one selection pill. Chips are separate pills with no track, so a chip's fill cross-fades instead.
- **Sheet springs:** a programmatic detent change (`animateToDetent`) uses the `emphasis` spring. A finger-release snap stays on `DraggableScrollableSheet`'s own snap, which can't take a spring, at the `emphasis` duration.
- **Top fade on home:** under the pinned header, done as a 16 px surface-to-clear strip that shows once the list scrolls (`BBSheet.fadeUnderHeader`). The bottom 24 px fade is a `ShaderMask`. It is off at peek, so the peek's last row stays crisp.
- **From/To rows as fields** (spec §2.2): the From row in the trip options becomes a field (surfaceField with an outline). The destination is the options sheet's title ("To Avalon Mall"), a header and not a field, so it keeps its title style.
- **Page transitions** (spec §3.2 "native on each platform") are out of scope. #19 shipped our own fade-and-slide with an iOS edge swipe, and this plan leaves it as it is.
- **Device check:** this plan runs it on an iOS simulator only. The developer checks their own iPhone.

```dart
/// Marks a sheet, panel or dialog. Cards inside one sit on `surface`, so they rise to
/// `surfaceRaised`, and chips use the field surface instead of floating (spec §2.1).
class BBSurfaceScope extends InheritedWidget {
  const BBSurfaceScope({super.key, required super.child});

  /// Whether [context] sits on a sheet, panel or dialog.
  static bool isRaised(BuildContext context) => context.dependOnInheritedWidgetOfExactType<BBSurfaceScope>() != null;

  /// The card decoration for where [context] sits.
  static BoxDecoration cardOf(BuildContext context, {double radius = BBRadius.card}) =>
      context.bb.card(radius: radius, raised: isRaised(context));

  @override
  bool updateShouldNotify(BBSurfaceScope oldWidget) => false;
}

class BBCard extends StatelessWidget {
  const BBCard({
    super.key,
    required this.child,
    this.onTap,
    this.padding = const EdgeInsets.symmetric(horizontal: BBSpace.m, vertical: 10),
    this.semanticLabel,
    this.exposeSemantics = true,
  });

  final Widget child;
  final VoidCallback? onTap;
  final EdgeInsetsGeometry padding;
  final String? semanticLabel;

  /// See [BBPressable.exposeSemantics].
  final bool exposeSemantics;

  @override
  Widget build(BuildContext context) {
    final box = DecoratedBox(
      decoration: BBSurfaceScope.cardOf(context),
      child: Padding(padding: padding, child: child),
    );
    if (onTap != null) {
      return BBPressable(onTap: onTap, semanticLabel: semanticLabel, exposeSemantics: exposeSemantics, child: box);

      return Semantics(label: semanticLabel, excludeSemantics: true, child: box);
```

```dart
import 'dart:io';

      file.writeAsStringSync(encodeHarbourStyle(buildHarbourStyle(upstream, palette)));
```

```dart
/// The motion system (visual refresh spec §3.1). Everything honours Reduce Motion
/// (`MediaQuery.disableAnimations`): [of] gives zero, [spring] a near-instant spring,
/// and loops don't run at all.
abstract final class BBMotion {
  /// Presses, toggles.
  static const quick = Duration(milliseconds: 120);

  /// Most fades and slides.
  static const standard = Duration(milliseconds: 220);

  /// Sheets snapping to detents, cards entering, the picker sheet (with [emphasisCurve]).
  static const emphasis = Duration(milliseconds: 360);

  /// Between list items as they enter, for at most [staggerMax] steps.
  static const stagger = Duration(milliseconds: 40);
  static const int staggerMax = 8;

  /// One live-dot breath cycle.
  static const pulse = Duration(milliseconds: 1600);

  /// A row becoming "Now": one scale 1 → 1.08 → 1.
  static const nowPulse = Duration(milliseconds: 600);

  static const Curve curve = Curves.easeOutCubic;

  /// Damping ratio ≈ 0.78, stiffness ≈ 260: a slight overshoot.
  static final SpringDescription emphasisSpring =
      SpringDescription.withDampingRatio(mass: 1, stiffness: 260, ratio: 0.78);

  /// Reduce Motion: critically damped and stiff, so it settles in a few milliseconds.
  static final SpringDescription reducedSpring =
      SpringDescription.withDampingRatio(mass: 1, stiffness: 10000, ratio: 1);

  /// [emphasisSpring] over [emphasis], for controller-driven motion.
  static final Curve emphasisCurve = BBSpringCurve(emphasisSpring, emphasis);

  /// Whether the user has asked the OS to reduce motion.
  static bool reduced(BuildContext context) => MediaQuery.maybeDisableAnimationsOf(context) == true;

  /// [d], or zero when the user has asked the OS to reduce motion.
  static Duration of(BuildContext context, Duration d) => reduced(context) ? Duration.zero : d;

  /// The emphasis spring, or a near-instant critically damped one under Reduce Motion.
  static SpringDescription spring(BuildContext context) => reduced(context) ? reducedSpring : emphasisSpring;
}

/// [spring] from 0 to 1 over [duration] as a [Curve], for AnimationController-driven motion.
/// It may overshoot 1 a little on the way; a linear correction lands it exactly on 1 at the end,
/// so the last frame doesn't jump.
class BBSpringCurve extends Curve {
  const BBSpringCurve(this.spring, this.duration);

  final SpringDescription spring;
  final Duration duration;

  @override
  double transformInternal(double t) {
    final seconds = duration.inMicroseconds / Duration.microsecondsPerSecond;
    final sim = SpringSimulation(spring, 0, 1, 0);
    return sim.x(t * seconds) + (1 - sim.x(seconds)) * t;
  }
}
```

```dart
import 'dart:async';

import 'package:flutter/widgets.dart';

/// A looping effect that runs for its controller's duration, rests for [rest], and runs again
/// (spec §3.1 `pulse`). The rests leave frame-free gaps: a screen with a loop still settles
/// between cycles, and the loop costs nothing while it rests. [run] starts or stops it; callers
/// pass whether motion is allowed, so under Reduce Motion it never starts.
class BBLoop {
  BBLoop({required TickerProvider vsync, required Duration active, required this.rest})
      : controller = AnimationController(vsync: vsync, duration: active) {
    controller.addStatusListener(_onStatus);
  }

  final AnimationController controller;
  final Duration rest;
  Timer? _timer;
  bool _running = false;

  bool get isRunning => _running;

  void _onStatus(AnimationStatus status) {
    if (status != AnimationStatus.completed || !_running) return;
    _timer?.cancel();
    _timer = Timer(rest, () {
      if (_running) controller.forward(from: 0);
    });
  }

  /// Starts the loop when [on]; otherwise stops it at 0 (the resting look).
  void run(bool on) {
    if (on == _running) return;
    _running = on;
    _timer?.cancel();
    if (on) {
      controller.forward(from: 0);
    } else {
      controller.stop();
      controller.value = 0;
    }
  }

  void dispose() {
    _running = false;
    _timer?.cancel();
    controller.dispose();
  }
}
```

```dart
import 'dart:math' as math;

import 'package:flutter/rendering.dart';
import 'package:flutter/scheduler.dart';
import 'package:flutter/widgets.dart';

import 'tokens.dart';

/// List motion (spec §3.2). Wrap a list's Column in [BBListMotion] and each item in a keyed
/// [BBListItem]:
/// - the first time the list shows items, they enter one after another ([BBMotion.stagger]
///   apart, at most [BBMotion.staggerMax] steps, each a [BBMotion.standard] fade and rise);
/// - items that appear later (a live refresh) show at once;
/// - with [slide], an item whose place changes (the list reorders, a row above it goes) slides
///   from its old place to its new one.
/// Reduce Motion turns all of it off.
class BBListMotion extends StatefulWidget {
  const BBListMotion({super.key, required this.child, this.slide = true});

  final Widget child;

  /// Slide moved items. Off for lazily built scrolling lists, where scrolling itself moves items.
  final bool slide;

  @override
  State<BBListMotion> createState() => _BBListMotionState();
}

class _EntranceGate {
  bool open = true;
  bool closing = false;
}

class _BBListMotionState extends State<BBListMotion> {
  final _gate = _EntranceGate();

  @override
  Widget build(BuildContext context) => _ListMotionScope(
        gate: _gate,
        child: widget.slide ? _MoveAnchor(child: widget.child) : widget.child,
      );
}

class _ListMotionScope extends InheritedWidget {
  const _ListMotionScope({required this.gate, required super.child});

  final _EntranceGate gate;

  @override
  bool updateShouldNotify(_ListMotionScope oldWidget) => false;
}

/// The frame of reference for [RenderBBSlideOnMove]: places are measured from here, so
/// scrolling the whole list never counts as a move.
class _MoveAnchor extends SingleChildRenderObjectWidget {
  const _MoveAnchor({super.child});

  @override
  RenderProxyBox createRenderObject(BuildContext context) => _RenderMoveAnchor();
}

class _RenderMoveAnchor extends RenderProxyBox {}

/// One item of a [BBListMotion] list. [index] is its place, for the entrance stagger.
class BBListItem extends StatefulWidget {
  const BBListItem({super.key, required this.index, required this.child});

  final int index;
  final Widget child;

  @override
  State<BBListItem> createState() => _BBListItemState();
}

class _BBListItemState extends State<BBListItem> with SingleTickerProviderStateMixin {
  AnimationController? _entrance;
  CurvedAnimation? _shown;
  bool _decided = false;
  bool _reduced = false;

  @override
  void didChangeDependencies() {
    super.didChangeDependencies();
    _reduced = BBMotion.reduced(context);
    if (_decided) return;
    _decided = true;
    final gate = context.getInheritedWidgetOfExactType<_ListMotionScope>()?.gate;
    if (gate == null || !gate.open || _reduced) return;
    if (!gate.closing) {
      gate.closing = true;
      // Everything that mounts in this first frame enters; anything later shows at once.
      WidgetsBinding.instance.addPostFrameCallback((_) => gate.open = false);
    }
    final delay = BBMotion.stagger * math.min(widget.index, BBMotion.staggerMax);
    final total = delay + BBMotion.standard;
    final controller = AnimationController(vsync: this, duration: total)..forward();
    _entrance = controller;
    _shown = CurvedAnimation(
      parent: controller,
      curve: Interval(delay.inMicroseconds / total.inMicroseconds, 1, curve: BBMotion.curve),
    );
  }

  @override
  void dispose() {
    _shown?.dispose();
    _entrance?.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    var child = widget.child;
    final shown = _shown;
    if (shown != null) {
      child = FadeTransition(
        opacity: shown,
        child: SlideTransition(
          position: shown.drive(Tween(begin: const Offset(0, 0.15), end: Offset.zero)),
          child: child,
        ),
      );
    }
    // Outermost, so the slide tracks the laid-out place, not the entrance's own rise.
    return BBSlideOnMove(enabled: !_reduced, child: child);
  }
}

/// Paints its child sliding from where it was last painted to where it is now, measured from
/// the nearest [BBListMotion], over [BBMotion.standard]. Used by [BBListItem].
class BBSlideOnMove extends SingleChildRenderObjectWidget {
  const BBSlideOnMove({super.key, required this.enabled, super.child});

  final bool enabled;

  @override
  RenderBBSlideOnMove createRenderObject(BuildContext context) => RenderBBSlideOnMove(enabled);

  @override
  void updateRenderObject(BuildContext context, RenderBBSlideOnMove renderObject) =>
      renderObject.enabled = enabled;
}

/// See [BBSlideOnMove]. The slide is paint-only: layout and hit testing use the new place at
/// once, so a tap mid-slide reaches the row that is really there.
class RenderBBSlideOnMove extends RenderProxyBox {
  RenderBBSlideOnMove(this._enabled);

  bool _enabled;
  set enabled(bool value) {
    if (value == _enabled) return;
    _enabled = value;
    _from = Offset.zero;
    _start = null;
    markNeedsPaint();
  }

  Offset? _lastPlace;
  Offset _from = Offset.zero;
  Duration? _start;

  /// How far from its laid-out place the child was last painted (zero when still).
  @visibleForTesting
  Offset lastShift = Offset.zero;

  Offset _shiftAt(Duration now) {
    final start = _start;
    if (start == null) return Offset.zero;
    final t = ((now - start).inMicroseconds / BBMotion.standard.inMicroseconds).clamp(0.0, 1.0);
    return t >= 1 ? Offset.zero : _from * (1 - BBMotion.curve.transform(t));
  }

  RenderObject? get _anchor {
    var node = parent;
    while (node != null && node is! _RenderMoveAnchor) {
      node = node.parent;
    }
    return node;
  }

  @override
  void paint(PaintingContext context, Offset offset) {
    final now = SchedulerBinding.instance.currentFrameTimeStamp;
    final anchor = _anchor;
    if (_enabled && anchor != null) {
      final t = getTransformTo(anchor).getTranslation();
      final place = Offset(t.x, t.y);
      final last = _lastPlace;
      _lastPlace = place;
      if (last != null && (last - place).distance > 0.5) {
        // Start from wherever the child shows now, mid-slide included.
        _from = last - place + _shiftAt(now);
        _start = now;
      }
    }
    final shift = _enabled ? _shiftAt(now) : Offset.zero;
    if (shift == Offset.zero) {
      _start = null;
    } else {
      SchedulerBinding.instance.scheduleFrameCallback((_) {
        if (attached) markNeedsPaint();
      });
    }
    lastShift = shift;
    super.paint(context, offset + shift);
  }
}
```

```dart
/// Days run from [first]'s day to [last]'s day; [first] is "now". Returns the picked moment (to
/// the minute), [first] when the rider picks "Use now instead" for a time in the past, or null
/// when they close it.
Future<DateTime?> showBBWhenPicker(
  BuildContext context, {
  required String title,
  required DateTime initial,
  required DateTime first,
  required DateTime last,
  required bool use24h,
}) {
  final wide = MediaQuery.sizeOf(context).shortestSide >= BBWhenPicker.wideBreakpoint;
  return showGeneralDialog<DateTime>(
    context: context,
    barrierDismissible: true,
    barrierLabel: 'Dismiss',
    barrierColor: BBScrim.strong,
    transitionDuration: BBMotion.of(context, BBMotion.emphasis),
    pageBuilder: (dialogContext, _, _) => BBWhenPicker(
      title: title,
      initial: initial,
      first: first,
      last: last,
      use24h: use24h,
      wide: wide,
      onDone: (picked) => Navigator.of(dialogContext).pop(picked),
    ),
    transitionBuilder: (_, animation, _, child) {
      final rise = animation.drive(CurveTween(curve: BBMotion.emphasisCurve));
      return FadeTransition(
        // Opacity stays within 0..1: it follows the plain curve, not the spring.
        opacity: animation.drive(CurveTween(curve: BBMotion.curve)),
        child: wide
            ? ScaleTransition(scale: rise.drive(Tween(begin: 0.94, end: 1.0)), child: child)
            : SlideTransition(position: rise.drive(Tween(begin: const Offset(0, 0.4), end: Offset.zero)), child: child),
      );
    },
  );
}

/// The picker sheet itself; [showBBWhenPicker] presents it. [onDone] gets the result.
class BBWhenPicker extends StatefulWidget {
  const BBWhenPicker({
    super.key,
    required this.title,
    required this.initial,
    required this.first,
    required this.last,
    required this.use24h,
    required this.onDone,
    this.wide = false,
  });

  /// "Leave by" or "Arrive by".
  final String title;
  final DateTime initial;

  /// The earliest moment (now): the first day, and the line before which a time is "in the past".
  final DateTime first;

  /// The last day with service.
  final DateTime last;
  final bool use24h;
  final ValueChanged<DateTime?> onDone;

  /// A centred card (tablets) instead of a bottom sheet.
  final bool wide;

  static const double wideBreakpoint = 600;
  static const sheetKey = ValueKey('bb-when-sheet');
  static const closeKey = ValueKey('bb-when-close');
  static const hourWheelKey = ValueKey('bb-when-hour');
  static const minuteWheelKey = ValueKey('bb-when-minute');
  static const periodWheelKey = ValueKey('bb-when-period');
  static const confirmKey = ValueKey('bb-when-confirm');
  static const pastKey = ValueKey('bb-when-past');
  static Key dayKey(int index) => ValueKey('bb-when-day-$index');

  @override
  State<BBWhenPicker> createState() => _BBWhenPickerState();
}

class _BBWhenPickerState extends State<BBWhenPicker> {
  late final List<DateTime> _days;
  late int _day;
  late int _hour; // 0–23
  late int _minute; // 0–59
  late final FixedExtentScrollController _hourWheel;
  late final FixedExtentScrollController _minuteWheel;
  late final FixedExtentScrollController _periodWheel;

  /// The wheels are being turned by code (a quick pick): no haptic ticks.
  bool _moving = false;

  @override
  void initState() {
    super.initState();
    final start = _dayOf(widget.first);
    final lastDay = _dayOf(widget.last);
    final end = lastDay.isBefore(start) ? start : lastDay;
    _days = [for (var d = start; !d.isAfter(end); d = DateTime(d.year, d.month, d.day + 1)) d];
    final initial = _clamp(_minuteOf(widget.initial));
    _day = _daysBetween(start, initial);
    _hour = initial.hour;
    _minute = initial.minute;
    _hourWheel = FixedExtentScrollController(initialItem: _hourItem(_hour));
    _minuteWheel = FixedExtentScrollController(initialItem: _minute);
    _periodWheel = FixedExtentScrollController(initialItem: _hour < 12 ? 0 : 1);
    WidgetsBinding.instance.addPostFrameCallback((_) {
      if (mounted) _announce('${widget.title}, ${_spoken(_value)}');
    });
  }

  @override
  void dispose() {
    _hourWheel.dispose();
    _minuteWheel.dispose();
    _periodWheel.dispose();
    super.dispose();
  }

  /// [t] with its day moved into the picker's days, its time of day kept.
  DateTime _clamp(DateTime t) {
    final day = _dayOf(t);
    final d = day.isBefore(_days.first) ? _days.first : (day.isAfter(_days.last) ? _days.last : day);
    return DateTime(d.year, d.month, d.day, t.hour, t.minute);
  }

  /// The hour wheel's item for [hour]: the hour itself in 24-hour mode; 0–11 for "1"–"12" otherwise.
  int _hourItem(int hour) => widget.use24h ? hour : (hour % 12 == 0 ? 11 : hour % 12 - 1);

  /// What the hour wheel shows for [hour].
  int _shownHour(int hour) => widget.use24h ? hour : (hour % 12 == 0 ? 12 : hour % 12);

  DateTime get _value {
    final d = _days[_day];
    return DateTime(d.year, d.month, d.day, _hour, _minute);
  }

  bool get _past => _value.isBefore(_minuteOf(widget.first));

  String _clock(DateTime t) => BBTime.of(t, use24h: widget.use24h);

  /// "today", "tomorrow", "Thursday", or "Thu, Oct 22" from a week out.
  String _dayWord(DateTime t) {
    final n = _daysBetween(_days.first, t);
    if (n == 0) return 'today';
    if (n == 1) return 'tomorrow';
    if (n < 7) return DateFormat('EEEE').format(t);
    return DateFormat('EEE, MMM d').format(t);
  }

  String _spoken(DateTime t) => '${_clock(t)} ${_dayWord(t)}';

  String _chipLabel(int i) {
    if (i == 0) return 'Today';
    if (i == 1) return 'Tomorrow';
    return DateFormat(i < 7 ? 'EEE' : 'EEE d').format(_days[i]);
  }

  String _chipSpoken(int i) {
    final full = DateFormat('EEEE, MMMM d').format(_days[i]);
    if (i == 0) return 'Today, $full';
    if (i == 1) return 'Tomorrow, $full';
    return full;
  }

  void _announce(String message) =>
      unawaited(SemanticsService.sendAnnouncement(View.of(context), message, Directionality.of(context)));

  void _tick() {
    if (!_moving) HapticFeedback.selectionClick();
  }

  void _onHour(int item) {
    setState(() => _hour = widget.use24h ? item : ((item + 1) % 12) + (_hour >= 12 ? 12 : 0));
    _tick();
  }

  void _onMinute(int item) {
    setState(() => _minute = item);
    _tick();
  }

  void _onPeriod(int item) {
    setState(() => _hour = _hour % 12 + (item == 1 ? 12 : 0));
    _tick();
  }

  /// Sets the day and time at once and turns the wheels to it.
  Future<void> _set(DateTime t) async {
    final target = _clamp(_minuteOf(t));
    setState(() {
      _day = _daysBetween(_days.first, target);
      _hour = target.hour;
      _minute = target.minute;
    });
    final d = BBMotion.of(context, BBMotion.standard);
    Future<void> turn(FixedExtentScrollController c, int item) async {
      if (!c.hasClients) return;
      if (d == Duration.zero) {
        c.jumpToItem(item);
      } else {
        await c.animateToItem(item, duration: d, curve: BBMotion.curve);
      }
    }

    _moving = true;
    await Future.wait([
      turn(_hourWheel, _hourItem(target.hour)),
      turn(_minuteWheel, target.minute),
      if (!widget.use24h) turn(_periodWheel, target.hour < 12 ? 0 : 1),
    ]);
    _moving = false;
    // The wheels report every item they pass; end exactly on the target.
    if (mounted) {
      setState(() {
        _hour = target.hour;
        _minute = target.minute;
      });
    }
  }

  /// Quick picks: label and moment, minus any after the last day.
  List<(String, String, DateTime)> get _quickPicks {
    final now = _minuteOf(widget.first);
    DateTime next(int hour) {
      final today = DateTime(now.year, now.month, now.day, hour);
      return today.isAfter(now) ? today : DateTime(now.year, now.month, now.day + 1, hour);
    }

    final eight = next(8), five = next(17);
    return [
      ('In 15 min', 'In 15 minutes', now.add(const Duration(minutes: 15))),
      ('In 30 min', 'In 30 minutes', now.add(const Duration(minutes: 30))),
      ('In 1 hr', 'In 1 hour', now.add(const Duration(hours: 1))),
      (_clock(eight), '${_clock(eight)} ${_dayWord(eight)}', eight),
      (_clock(five), '${_clock(five)} ${_dayWord(five)}', five),
    ].where((p) => !_dayOf(p.$3).isAfter(_days.last)).toList();
  }

  void _confirm() {
    final picked = _past ? widget.first : _value;
    _announce('${widget.title} ${_spoken(picked)}');
    widget.onDone(picked);
  }

  Widget _wheel({
    required Key key,
    required FixedExtentScrollController controller,
    required int count,
    required String Function(int) label,
    required int selectedItem,
    required ValueChanged<int> onChanged,
    required String semanticLabel,
    required String value,
    required String? increased,
    required String? decreased,
    required VoidCallback? onIncrease,
    required VoidCallback? onDecrease,
    required double itemExtent,
    required int visible,
  }) {
    final bb = context.bb;
    return Semantics(
      container: true,
      slider: true,
      label: semanticLabel,
      value: value,
      increasedValue: increased,
      decreasedValue: decreased,
      onIncrease: onIncrease,
      onDecrease: onDecrease,
      child: ExcludeSemantics(
        child: SizedBox(
          height: itemExtent * visible,
          child: ListWheelScrollView.useDelegate(
            key: key,
            controller: controller,
            itemExtent: itemExtent,
            physics: const FixedExtentScrollPhysics(),
            diameterRatio: 1.6,
            overAndUnderCenterOpacity: 0.45,
            onSelectedItemChanged: onChanged,
            childDelegate: ListWheelChildBuilderDelegate(
              childCount: count,
              builder: (context, i) => Center(
                child: Text(
                  label(i),
                  maxLines: 1,
                  style: bb.text.title.copyWith(
                    color: i == selectedItem ? bb.colors.ink : bb.colors.muted,
                    fontFeatures: const [FontFeature.tabularFigures()],
                  ),
                ),
              ),
            ),
          ),
        ),
      ),
    );
  }

  Widget _wheels(double itemExtent, int visible) {
    final bb = context.bb;
    final d = _days[_day];
    DateTime at(int hour, int minute) => DateTime(d.year, d.month, d.day, hour, minute);
    String hours(int h) => '$h ${h == 1 ? 'hour' : 'hours'}';
    String minutes(int m) => '$m ${m == 1 ? 'minute' : 'minutes'}';
    final pm = _hour >= 12;
    return Stack(
      alignment: Alignment.center,
      children: [
        // The selection band.
        IgnorePointer(
          child: Container(
            height: itemExtent,
            decoration: BoxDecoration(color: bb.colors.brandSoft, borderRadius: BorderRadius.circular(BBRadius.button)),
          ),
        ),
        Row(
          children: [
            Expanded(
              child: _wheel(
                key: BBWhenPicker.hourWheelKey,
                controller: _hourWheel,
                count: widget.use24h ? 24 : 12,
                label: (i) => widget.use24h ? i.toString().padLeft(2, '0') : '${i + 1}',
                selectedItem: _hourItem(_hour),
                onChanged: _onHour,
                semanticLabel: 'Hour',
                value: hours(_shownHour(_hour)),
                increased: _hour < 23 ? hours(_shownHour(_hour + 1)) : null,
                decreased: _hour > 0 ? hours(_shownHour(_hour - 1)) : null,
                onIncrease: _hour < 23 ? () => _set(at(_hour + 1, _minute)) : null,
                onDecrease: _hour > 0 ? () => _set(at(_hour - 1, _minute)) : null,
                itemExtent: itemExtent,
                visible: visible,
              ),
            ),
            ExcludeSemantics(child: Text(':', style: bb.text.title)),
            Expanded(
              child: _wheel(
                key: BBWhenPicker.minuteWheelKey,
                controller: _minuteWheel,
                count: 60,
                label: (i) => i.toString().padLeft(2, '0'),
                selectedItem: _minute,
                onChanged: _onMinute,
                semanticLabel: 'Minute',
                value: minutes(_minute),
                increased: _minute < 59 ? minutes(_minute + 1) : null,
                decreased: _minute > 0 ? minutes(_minute - 1) : null,
                onIncrease: _minute < 59 ? () => _set(at(_hour, _minute + 1)) : null,
                onDecrease: _minute > 0 ? () => _set(at(_hour, _minute - 1)) : null,
                itemExtent: itemExtent,
                visible: visible,
              ),
            ),
            if (!widget.use24h)
              Expanded(
                child: _wheel(
                  key: BBWhenPicker.periodWheelKey,
                  controller: _periodWheel,
                  count: 2,
                  label: (i) => i == 0 ? 'AM' : 'PM',
                  selectedItem: pm ? 1 : 0,
                  onChanged: _onPeriod,
                  semanticLabel: 'AM or PM',
                  value: pm ? 'PM' : 'AM',
                  increased: pm ? null : 'PM',
                  decreased: pm ? 'AM' : null,
                  onIncrease: pm ? null : () => _set(at(_hour + 12, _minute)),
                  onDecrease: pm ? () => _set(at(_hour - 12, _minute)) : null,
                  itemExtent: itemExtent,
                  visible: visible,
                ),
              ),
          ],
        ),
      ],
    );
  }

  Widget _chip({
    Key? key,
    required String label,
    required String semanticLabel,
    required bool selected,
    required VoidCallback onTap,
    bool selectable = true,
  }) {
    final bb = context.bb;
    final pill = BBPressable(
      key: key,
      haptic: !selected,
      semanticLabel: semanticLabel,
      onTap: onTap,
      child: AnimatedContainer(
        duration: BBMotion.of(context, BBMotion.standard),
        curve: BBMotion.curve,
        constraints: const BoxConstraints(minHeight: 44),
        padding: const EdgeInsets.symmetric(horizontal: BBSpace.l, vertical: BBSpace.s),
        // Selected: the brand fill with onBrand text (spec §4.1).
        decoration: selected
            ? BoxDecoration(color: bb.colors.brand, borderRadius: BorderRadius.circular(22))
            : bb.field(radius: 22),
        // As wide as its label (no `alignment`, which would fill a Wrap's width), centred in the 44 pt height.
        child: Row(
          mainAxisSize: MainAxisSize.min,
          children: [
            Text(
              label,
              maxLines: 1,
              style: bb.text.label.copyWith(color: selected ? bb.colors.onBrand : bb.colors.ink),
            ),
          ],
        ),
      ),
    );
    if (!selectable) return pill;
    return Semantics(selected: selected, inMutuallyExclusiveGroup: true, child: pill);
  }

  @override
  Widget build(BuildContext context) {
    final bb = context.bb;
    final media = MediaQuery.of(context);
    final textScale = media.textScaler.scale(1);
    // Wheel rows grow with the text (spec §4.2); at large sizes, three rows show instead of five.
    final itemExtent = media.textScaler.scale(bb.text.title.fontSize!) * 1.6;
    final visible = textScale > 1.3 ? 3 : 5;
    final value = _value;
    final past = _past;
    const radius = Radius.circular(BBRadius.sheet);

    final sheet = Container(
      key: BBWhenPicker.sheetKey,
      decoration: bb.floating(
        borderRadius: widget.wide ? BorderRadius.all(radius) : BorderRadius.vertical(top: radius),
      ),
      child: BBSurfaceScope(
        child: SafeArea(
          top: false,
          bottom: !widget.wide,
          child: SingleChildScrollView(
            padding: const EdgeInsets.fromLTRB(BBSpace.l, BBSpace.s, BBSpace.l, BBSpace.l),
            child: Column(
              mainAxisSize: MainAxisSize.min,
              crossAxisAlignment: CrossAxisAlignment.stretch,
              children: [
                Row(
                  children: [
                    Expanded(
                      child: Semantics(header: true, child: Text(widget.title, style: bb.text.title)),
                    ),
                    BBIconButton(
                      key: BBWhenPicker.closeKey,
                      icon: BBIcons.close,
                      semanticLabel: 'Close',
                      onPressed: () => widget.onDone(null),
                    ),
                  ],
                ),
                const SizedBox(height: BBSpace.s),
                SingleChildScrollView(
                  scrollDirection: Axis.horizontal,
                  child: Row(
                    children: [
                      for (var i = 0; i < _days.length; i++) ...[
                        if (i > 0) const SizedBox(width: BBSpace.s),
                        _chip(
                          key: BBWhenPicker.dayKey(i),
                          label: _chipLabel(i),
                          semanticLabel: _chipSpoken(i),
                          selected: i == _day,
                          onTap: () => setState(() => _day = i),
                        ),
                      ],
                    ],
                  ),
                ),
                const SizedBox(height: BBSpace.m),
                _wheels(itemExtent, visible),
                if (past)
                  Padding(
                    padding: const EdgeInsets.only(top: BBSpace.s),
                    child: Semantics(
                      liveRegion: true,
                      child: Text(
                        "That's in the past",
                        key: BBWhenPicker.pastKey,
                        textAlign: TextAlign.center,
                        style: bb.text.caption,
                      ),
                    ),
                  ),
                const SizedBox(height: BBSpace.m),
                Wrap(
                  spacing: BBSpace.s,
                  runSpacing: BBSpace.s,
                  children: [
                    for (final (label, spoken, t) in _quickPicks)
                      _chip(label: label, semanticLabel: spoken, selected: false, selectable: false, onTap: () => _set(t)),
                  ],
                ),
                const SizedBox(height: BBSpace.l),
                BBButton(
                  key: BBWhenPicker.confirmKey,
                  label: past ? 'Use now instead' : 'Set ${_clock(value)} ${_dayWord(value)}',
                  expand: true,
                  wrap: true,
                  onPressed: _confirm,
                ),
              ],
            ),
          ),
        ),
      ),
    );

    final maxHeight = math.max(0.0, media.size.height - media.padding.top - BBSpace.xxl);
    return DefaultTextStyle(
      style: bb.text.body,
      child: Semantics(
        scopesRoute: true,
        namesRoute: true,
        explicitChildNodes: true,
        label: widget.title,
        child: widget.wide
            ? Center(
                child: ConstrainedBox(
                  constraints: BoxConstraints(maxWidth: 420, maxHeight: maxHeight),
                  child: sheet,
                ),
              )
            : Align(
                alignment: Alignment.bottomCenter,
                child: ConstrainedBox(constraints: BoxConstraints(maxHeight: maxHeight), child: sheet),
              ),
      ),
    );
  }
}
```

Notes for the implementer:
- `ListWheelScrollView` reports every item it passes. That's why `_set` lands the state on the target again after the wheels stop, and why `_moving` mutes the haptic ticks while code turns them.
- `FontFeature` comes from `package:flutter/widgets.dart` (via painting). `BBTime`'s 24-hour form pads the hour ("08:35"), so the button reads "Set 08:35 today".

```dart
import 'dart:ui' show ImageFilter;

import 'package:flutter/rendering.dart';
import 'package:flutter/widgets.dart';

import 'bb_top_bar.dart';
import 'tokens.dart';

/// A pushed page (Alerts, Settings, Search) whose content scrolls under its top bar (spec §5).
/// At rest the bar is clear over `bg`, with the large title. Once content scrolls under it, the
/// title condenses (at once under Reduce Motion), and the bar frosts (blur 16, `bg` at 80%) and
/// gets a `line` hairline. [below] (Search's field) sits in the bar, under the title.
///
/// [body] builds the scrolling content. Pad its top by `topInset` (the bar's height), so its first
/// item starts below the bar and scrolls up under it.
class BBScrollPage extends StatefulWidget {
  const BBScrollPage({
    super.key,
    required this.title,
    this.subtitle,
    this.onBack,
    this.actions = const [],
    this.large = false,
    this.below,
    required this.body,
  });

  final String title;
  final String? subtitle;
  final VoidCallback? onBack;
  final List<Widget> actions;
  final bool large;
  final Widget? below;
  final Widget Function(BuildContext context, double topInset) body;

  static const barKey = ValueKey('bb-scroll-page-bar');

  @override
  State<BBScrollPage> createState() => _BBScrollPageState();
}

class _BBScrollPageState extends State<BBScrollPage> {
  bool _under = false;
  double _inset = 0;

  bool _onScroll(ScrollNotification n) {
    if (n.depth != 0 || n.metrics.axis != Axis.vertical) return false;
    final under = n.metrics.pixels > 0.5;
    if (under != _under) setState(() => _under = under);
    return false;
  }

  /// The inset follows the bar at rest only: while condensed the bar is shorter, and moving the
  /// list's padding then would make the content jump.
  void _onBarHeight(double height) {
    if (!mounted || _under || (height - _inset).abs() <= 0.5) return;
    setState(() => _inset = height);
  }

  @override
  Widget build(BuildContext context) {
    final bb = context.bb;
    final under = _under;
    return Stack(
      children: [
        Positioned.fill(
          child: NotificationListener<ScrollNotification>(
            onNotification: _onScroll,
            child: widget.body(context, _inset),
          ),
        ),
        Positioned(
          top: 0,
          left: 0,
          right: 0,
          child: ClipRect(
            child: BackdropFilter(
              enabled: under,
              filter: ImageFilter.blur(sigmaX: 16, sigmaY: 16),
              child: DecoratedBox(
                key: BBScrollPage.barKey,
                decoration: BoxDecoration(
                  color: under ? bb.colors.bg.withValues(alpha: 0.8) : const Color(0x00000000),
                  border: under ? Border(bottom: BorderSide(color: bb.colors.line)) : null,
                ),
                child: _MeasureHeight(
                  onHeight: _onBarHeight,
                  child: Column(
                    mainAxisSize: MainAxisSize.min,
                    crossAxisAlignment: CrossAxisAlignment.stretch,
                    children: [
                      BBTopBar(
                        title: widget.title,
                        subtitle: widget.subtitle,
                        onBack: widget.onBack,
                        actions: widget.actions,
                        large: widget.large,
                        condensed: under,
                      ),
                      ?widget.below,
                    ],
                  ),
                ),
              ),
            ),
          ),
        ),
      ],
    );
  }
}

/// Reports its child's height after each layout that changes it.
class _MeasureHeight extends SingleChildRenderObjectWidget {
  const _MeasureHeight({required this.onHeight, super.child});

  final ValueChanged<double> onHeight;

  @override
  RenderObject createRenderObject(BuildContext context) => _RenderMeasureHeight(onHeight);

  @override
  void updateRenderObject(BuildContext context, _RenderMeasureHeight renderObject) => renderObject.onHeight = onHeight;
}

class _RenderMeasureHeight extends RenderProxyBox {
  _RenderMeasureHeight(this.onHeight);

  ValueChanged<double> onHeight;
  double? _last;

  @override
  void performLayout() {
    super.performLayout();
    final height = size.height;
    if (height == _last) return;
    _last = height;
    // Not during layout: the page rebuilds with the new inset after this frame.
    WidgetsBinding.instance.addPostFrameCallback((_) => onHeight(height));
  }
}
```

```dart
/// The pixel at ([x], [y]) of the PNG at [path].
Future<ui.Color> _pixel(String path, int x, int y) async {
  final codec = await ui.instantiateImageCodec(File(path).readAsBytesSync());
  final image = (await codec.getNextFrame()).image;
  final data = (await image.toByteData(format: ui.ImageByteFormat.rawRgba))!;
  final i = (y * image.width + x) * 4;
  return ui.Color.fromARGB(data.getUint8(i + 3), data.getUint8(i), data.getUint8(i + 1), data.getUint8(i + 2));
}
```
